# Data

Raw data is NOT committed to this repo.

Dataset: Martinez et al., "Production Data Set for Five-Axis CNC Milling with Multiple Changeovers", Scientific Data (2025).
- Paper: https://www.nature.com/articles/s41597-025-05294-0
- Data (Zenodo): https://zenodo.org/records/14710224
- Supplementary material: https://github.com/ElMoe/Production-Data-Set-for-Five-Axis-CNC-Milling-with-Multiple-Changeovers

Download the CSV and place it in this folder (data/). It is git-ignored.
